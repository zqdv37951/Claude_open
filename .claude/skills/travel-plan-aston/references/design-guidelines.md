# 内置美学准则（无 frontend-design 时的兜底）

设计步骤优先调用专业设计 skill（`frontend-design` 或 `huashu-design` 花叔Design，任一已安装即用）；**两者都未安装**时，按本准则自己出风格化 HTML，目标是"有性格、不像 AI 默认模板"。这是本仓库自有的精简指导，使 skill 可独立使用。

## 配色

- **所有行程（不分单日/多日、国内/跨国），预设直接套用 `references/trip-extras.md` 第7节的固定色票**（teal + amber，浅/深双主题），不用每次重新设计或询问用户偏好。
- 用户明确提供另一份参考页面并表示喜欢该配色时，优先级高于上一条：直接沿用对方的 CSS 变量命名与数值（含浅/深双主题的三段式写法：裸 `:root` 定义浅色、`@media (prefers-color-scheme: dark)` 搭配 `:not([data-theme="light"])`、`:root[data-theme="dark"]` 三层），完整套用而非只挑几个颜色片段、也不要混用两边变量名。
- 其余情况（多日跨国行程等不适用上述固定色票时），每趟行程选一套**有性格的配色**（深色背景 + 主题强调色，或清爽浅色 + 一个鲜明主色），不同行程用不同配色以便区分。
- 用 CSS 变量统一定义（如 `--bg`、`--bg-card`、`--text`、`--text-dim`、`--accent`、`--border`），全局复用。
- 保证文字与背景**高对比**，可读性第一。

## 排版与布局

- **响应式，移动 + 桌面都要好看**：手机端单列、主体约 420–480px；**桌面端（≥768px）容器加宽到约 880–960px 居中**，卡片列表（航班/酒店/行前须知/餐饮/景点）用多列网格、地图更宽。务必写 `@media` 断点，别让大屏只剩一条窄列。
- 层级分明：标题用有个性的字体（衬线/展示体皆可），正文清爽易读；字号、字重拉开层级。
- **卡片化**：分区用卡片承载，圆角、充足留白、细边框或极淡阴影，不要拥挤。
- 一致的视觉语言：图标、徽章、标签"药丸"风格统一（如营业时间/门票/交通用同一套小标签，`.source-tag` 来源标签、`.pill` 营业时间/门票标签、`.dist-tag` 距离标签都算在内，别让 `poi.js` 产出的这几个 class 长得像没设计过的浏览器默认样式）。

## POI 卡片墙（延伸推荐总览 / 每站附近推荐面板）

结构与版面（几列、横向卷动、滚动提示的触发时机）由 `trip-extras.md` 第 2、3 节和 `assets/poi.js` 定死，这里只管视觉——`poi.js` 只产生语义化的 class（`.poi-grid`、`.poi-card`、`.source-tag.highlight`/`.source-tag.transit`、`.dist-tag`、`.poi-maplink`、`.poi-scroll-hint`），具体长什么样由设计步骤决定：

- **`.source-tag` 的两个变体要一眼区分**：`.highlight`（精选）用页面主色调，`.transit`（行程途经）用次色调或中性色——不要两个用同一个颜色只靠文字区分，那样在卡片墙快速扫视时起不到分组的作用。可以直接借用第 5 节配色里的主色/次色（如 teal/amber 那组配色里，精选用 `--teal-soft` 底 + `--teal-ink` 字，行程途经用中性的 `--surface-2` 底 + `--ink-soft` 字，或反过来用 amber 当次色，视整体配色而定）。
- **`.poi-scroll-hint` 要低调，不要抢戏**：这只是个「还能往右滑」的辅助提示，用小字号、弱化的次要文字颜色（如 `--ink-faint`）即可，不需要图标动画或强调色，喧宾夺主反而分散注意力。
- **`.poi-card` 内容密度**：卡片可能同时有标题＋标签＋备注＋地图连结，行距与内边距要给够，避免挤成一团；`.poi-maplink` 的小连结建议跟卡片正文有明显字号差（比正文小一号），视觉上读作"附属操作"而非"正文内容"。
- **横向卷动的视觉边界**：卡片牆末端如果卡片被截断一半，读者更容易意识到还能往右滑；不需要额外做渐层遮罩这类效果，`.poi-scroll-hint` 加上被截断的卡片边缘已经足够。
- **`.action-link`（航班/酒店/交通的行动按钮，见 page-contract.md「可选适配元素」）**：跟卡片里静态的 `.poi-maplink` 不同，这是「去预订/去导航/叫车」这类会触发实际动作的按钮，视觉权重要比 `.poi-maplink` 明显——用主色（如 `--teal-ink`）加粗体或底线强调，让读者一眼认出"这个可以点、会带我去下一步"，不要跟卡片里其他辅助小字混在一起。

## 细节

- 图片**严禁变形**：容器固定尺寸/比例，`<img>` 用 `object-fit: cover` + `display:block`（推荐绝对定位 `inset:0` 填满）。
- 关键信息（待办清单、⚠️ 提醒徽章、已预订标识、免责声明）用颜色/图标突出，但克制，不要花哨到喧宾夺主。
- 适度的过渡/悬停反馈即可，避免炫技动画拖慢手机。
- 整体追求"精心设计过"的观感，避免千篇一律的默认灰白卡片。

> 装了 frontend-design 或 huashu-design 会更出彩；本准则只是保证"没装也能拿到一份像样、好看的页面"。
