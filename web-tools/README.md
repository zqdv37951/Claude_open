# Web Tools

單一檔案、不需安裝、直接用瀏覽器開啟即可使用的小工具。

## 檔案清單

| 檔案 | 用途 |
|---|---|
| [`gallery-viewer.html`](gallery-viewer.html) | 本機圖片資料夾瀏覽器。用 File System Access API 選取一個本機資料夾(遞迴掃描含子資料夾的圖片),依檔名排序（和 Finder 一樣：數字依數值、英文不分大小寫、中日文依系統語系；書的順序也是）後直接在網頁裡瀏覽,支援雙頁模式、章節(子資料夾)導覽、閱讀進度與最近 5 筆閱讀紀錄記憶、圖片寬度調整；選一個大資料夾時,裡面**任何一層、直接放著圖片的資料夾都是一本書**(大資料夾根目錄的散圖也算一本,書名用大資料夾的名字;書名只用資料夾自己的名稱,同名會標 ⚠ 提醒),工具列「📚」書櫃列出所有書、切換、顯示各自讀到第幾張,每本書的進度各自獨立；**這個頁面本身沒有「加入圖書館」、不上傳、不同步**——記進圖書館（進度與封面）只有裝了油猴閱讀器才有，由它的 📚 決定（每本書各自決定、預設記、每次改變就成為下一本書的預設；封面用那本書的第一張圖），讓 `manga-library.html` 把它當成「本機資料夾」作品；從圖書館點「繼續閱讀」會用網址 `#資料夾名稱` 自動打開那個資料夾。如果你裝了油猴閱讀器(`manga-desktop-reader`),它會把這個頁面當成又一個閱讀網站接管版面(寬度、雙頁、書籤、快捷鍵、進度、記進圖書館都由它負責),這個頁面只負責選資料夾並提供圖片;沒裝就用這個頁面自己的介面(原樣)。僅支援 Chrome / Edge(Safari 不支援 `showDirectoryPicker`)。 |
| [`dragon-english-anki.html`](dragon-english-anki.html) | 「ドラゴン・イングリッシュ基本英文100」的 Anki 式間隔複習卡片：100 句中／日／英對照，可選正面語言、Again／Hard／Good／Easy 評分與下次複習間隔預覽、每日新卡上限、復原、日文／英文朗讀音檔（見下方說明；中文沒有）、日文與英文句子下方預設收合的「文法・單字」說明（英文或日文與原書不同時，會列出原書寫法對照），另有「全部詞條」頁籤可搜尋、依狀態篩選、模糊遮蓋任一語言自我測驗。另有「測驗」頁籤：可選範圍（全部／學習中・複習中／最近答錯／編號區間）與題數，題型有選擇題（中⇄英）、填空、拼寫、排序；測驗不會改動學習進度，結束後可選擇把答錯的卡加入學習，答錯統計可在「全部詞條」用「測驗答錯過」篩選。進度存在瀏覽器 localStorage。 |
| [`manga-library.html`](manga-library.html) | 漫畫圖書館：唯讀的封面牆網頁，讀你自己的 Google 試算表（閱讀紀錄）與 Drive（封面）。第一次打開填入自己的 Apps Script 網址與密鑰（只存在該瀏覽器的 localStorage，頁面本身不含任何資料或密鑰）。封面牆／清單、「接著看」、搜尋語法（`tag:` `site:` `author:` `note:`）、狀態與網站篩選、各網站進度與一鍵繼續閱讀、深色／淺色、手機版面、離線快取。已加 `noindex`。由 `Claude_private` 裡的 `tampermonkey-scripts/library/` 產生。 |

### `dragon-english-anki-audio/`

`dragon-english-anki.html` 的朗讀音檔：`ja/001.mp3`～`ja/100.mp3`、`en/001.mp3`～`en/100.mp3`，檔名編號對應詞條編號，共約 7 MB。HTML 與此資料夾必須放在同一層。頁面開啟後會在背景把全部音檔預載進瀏覽器快取（需 https，例如 GitHub Pages；`file://` 雙擊開啟時略過，改為即時串流），之後播放不必等網路。

英文句子以「忠於日文原意、自然好學」為原則做過校訂（共改了 34 句；中文 8 句、日文 1 句），原書寫法保留在各句的說明裡。音檔是用開源模型 Kokoro-82M（Apache-2.0）合成的 AI 語音，不是真人錄音——日文 `jf_alpha`、英文 `af_heart`，語速 0.95。日文先用 OpenJTalk 對照過數字、量詞與多音字的讀音（例如 2階、20分、日本人、私），有誤的詞在合成前改成假名；再用語音辨識轉回文字比對，日文讀音層級相似度約 99%、英文約 99.5%。找不到音檔時，頁面會退回瀏覽器內建語音。

## 使用方式

直接用 Chrome 或 Edge 開啟對應的 `.html` 檔案(雙擊或拖曳進瀏覽器分頁即可,不需要伺服器或安裝)。`gallery-viewer.html` 可以放在電腦上任何位置,不需要跟圖片資料夾放在一起;選過一次資料夾後,同一台電腦、同一個瀏覽器重開網頁會透過 IndexedDB 自動記住授權,不用每次重選。
